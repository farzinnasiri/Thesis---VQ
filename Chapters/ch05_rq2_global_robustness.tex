\chapter{Robustness to Global Perturbations}
\label{ch:rq2}

With the clean-image baseline established, this chapter turns to the effect of noise. Gaussian noise is added to each input image before tokenization, and the tokenizer response is measured along three dimensions: image-space fidelity, exact token identity stability, and the aggregate codebook distribution. Token identity stability means that a token-grid position keeps the same discrete code as in the clean image. The main question is whether image quality and token stability degrade together. The answer is no: reconstruction quality degrades gradually with noise level, while exact token identities change sharply. At the lowest perturbation level tested ($\sigma=0.1$), over three-quarters of token positions already carry a different code than they did on the clean image.

\section{Motivation}
\label{sec:rq2_motivation}

An image tokenizer sits between continuous image space and discrete sequence modeling. Robustness therefore has two distinct aspects: whether the decoded image remains visually faithful, and whether the sequence of code indices remains stable. The distinction matters because an autoregressive model sees the token sequence, not the pixels. A reconstruction can still look recognizable even when the sequence used to reconstruct it is mostly different.

Vector-quantized tokenizers are especially sensitive to this distinction. In the continuous encoder space, a perturbation may move a latent vector by a small Euclidean distance. In the discrete representation, however, the same movement can cross a nearest-neighbor boundary and replace one token by another, as discussed in Chapter~\ref{ch:background}. If many latent vectors lie near codebook cell boundaries, a global image perturbation may produce widespread token replacement even when the decoded image still resembles the original. This chapter tests that possibility directly.

Global Gaussian noise is not intended here as a comprehensive benchmark of corruptions. It is used as a controlled probe. Unlike local patch perturbations, which will be studied in Chapter~\ref{ch:rq3}, global noise affects the whole image and therefore tests the overall stability of the encoder-tokenizer-decoder pipeline. The experiment establishes whether exact token identities are already unstable under a simple input perturbation before more localized mechanisms are isolated.

\section{Experimental Setup}
\label{sec:rq2_setup}

\subsection{Perturbation Protocol}
\label{subsec:rq2_perturbation_protocol}

Let $x \in [0,1]^{H \times W \times 3}$ denote a preprocessed ImageNet validation image. For a noise level $\sigma$, the perturbed image is defined by Equation~\ref{eq:rq2_global_noise}:
\begin{equation}
    x_{\sigma} = \mathrm{clip}(x + \sigma \epsilon, 0, 1),
    \qquad
    \epsilon \sim \mathcal{N}(0, I).
    \label{eq:rq2_global_noise}
\end{equation}
The clipping operation keeps the perturbed image in the valid pixel range. Because pixel intensities are normalized to $[0,1]$, these noise levels are visually meaningful: $\sigma=0.1$ is a visible but moderate corruption, while $\sigma=0.5$ is a severe perturbation. The experiment uses $\sigma \in \{0.1, 0.2, 0.5\}$, together with the clean baseline $\sigma=0$.

For a tokenizer with encoder $E$, quantizer $q$, and decoder $D$, Equation~\ref{eq:rq2_reconstruction_tokenization} defines the reconstruction and discrete tokenization obtained from the perturbed image:
\begin{equation}
    \hat{x}_{\sigma} = D(q(E(x_{\sigma}))),
    \qquad
    z_{\sigma} = q(E(x_{\sigma})).
    \label{eq:rq2_reconstruction_tokenization}
\end{equation}
The clean reconstruction and tokenization are $\hat{x}_0$ and $z_0$. Each $z_{\sigma}$ is a $16 \times 16$ token grid, so every image contributes 256 token positions at each noise level.

The experiment was run on the full ImageNet validation set for both tokenizers. Each of the 50{,}000 images contributes one clean tokenization and three noisy tokenizations, corresponding to $\sigma=0.1$, $\sigma=0.2$, and $\sigma=0.5$.

Both exporters set the Python, NumPy, and PyTorch seeds to zero. The runs are
reproducible within each implementation, but the Gaussian arrays were not
exported and reused across tokenizers; model-to-model comparisons are matched
by image and noise level, not by an identical realization of every noise
value. Inputs are transformed to each model's internal $[-1,1]$ range and
outputs are converted to $[0,1]$ for image metrics.

\subsection{Metrics}
\label{subsec:rq2_metrics}

The image-space metrics separate three effects. The first is the strength of the input corruption, $\mathrm{PSNR}(x,x_{\sigma})$. The second is how well the tokenizer reconstructs the corrupted input, $\mathrm{PSNR}(x_{\sigma},\hat{x}_{\sigma})$; this indicates whether the decoder follows the noisy image itself or discards part of the corruption. The third, defined in Equation~\ref{eq:rq2_clean_psnr}, is the end-to-end fidelity to the original clean image:
\begin{equation}
    \mathrm{PSNR}_{\mathrm{clean}}(\sigma)
    =
    \mathrm{PSNR}(x,\hat{x}_{\sigma}).
    \label{eq:rq2_clean_psnr}
\end{equation}
The third quantity is the main reconstruction metric in this chapter because it measures what remains of the original image after the perturbation has passed through the tokenizer.

Token identity stability is measured by the fraction of token positions that change relative to the clean tokenization, as in Equation~\ref{eq:rq2_token_flip}:
\begin{equation}
    \mathrm{flip}_{\sigma}(x)
    =
    \frac{1}{N}
    \sum_{i=1}^{N}
    \mathbf{1}\!\left[z_{\sigma,i} \neq z_{0,i}\right],
    \label{eq:rq2_token_flip}
\end{equation}
where $N=256$ is the number of positions in the $16 \times 16$ token grid. A value near zero indicates that most positions keep the same token under noise; a value near one indicates that nearly all token identities changed.

Flip rates are directly comparable across noise levels within a tokenizer.
Their absolute values are only descriptive across tokenizers: LlamaGen uses
almost the full nominal vocabulary, whereas VQGAN quantizes into a much
smaller empirical subset, and the two codebooks induce different partitions
of latent space. A higher cross-model flip rate therefore does not by itself
imply a worse representation.

Finally, the global token distribution is computed by aggregating token counts over the entire validation set at each noise level. For empirical token probabilities $p_k$, Equation~\ref{eq:rq2_perplexity} gives the entropy and corresponding perplexity:
\begin{equation}
    H(p) = -\sum_k p_k \log p_k,
    \qquad
    \mathrm{PPL}(p) = \exp(H(p)).
    \label{eq:rq2_perplexity}
\end{equation}
The analysis also reports the number of active codes and the mass assigned to the most frequent 100 and 1000 codes.

\section{Experimental Results}

\subsection{Qualitative Behavior}
\label{subsec:rq2_qualitative}

Figures~\ref{fig:rq2_qual_vqgan} and~\ref{fig:rq2_qual_llamagen} show the same selected ImageNet examples for VQGAN and LlamaGen. The examples are used as qualitative checks across natural texture, structured geometry, and fine object detail; the quantitative conclusions come from the full validation set. Each example contains the clean image, three noisy inputs, the clean reconstruction, and three noisy-input reconstructions. The qualitative behavior is consistent with the intended perturbation protocol: noise is visible across the whole image, but object identity and global layout often remain recognizable, especially at $\sigma=0.1$ and $\sigma=0.2$.

The qualitative figures also show why a purely visual inspection would miss part of the behavior. The reconstructions remain structured, but the token flip-rate results in Section~\ref{subsec:rq2_token_flip} show that the underlying discrete representation changes at most positions. In other words, the decoder can map substantially different token grids to images that still preserve coarse content.

\subsection{Image-Space Degradation}
\label{subsec:rq2_image_space}

Table~\ref{tab:rq2_psnr_summary} reports $\mathrm{PSNR}(x,\hat{x}_{\sigma})$, the end-to-end fidelity of the noisy-input reconstruction to the original clean image. Figure~\ref{fig:rq2_psnr_x_xhat} visualizes the same trend. Both tokenizers degrade monotonically as $\sigma$ increases, and LlamaGen remains above VQGAN at every level. At the clean baseline, LlamaGen reaches $20.79$ dB and VQGAN reaches $19.65$ dB. At the highest perturbation level, LlamaGen remains at $16.22$ dB, while VQGAN falls to $14.90$ dB.

The gap is therefore not introduced only by noise; it is already present in clean reconstruction and persists under perturbation. However, the high-noise regime widens the practical difference because both systems are pushed into a lower-fidelity range.

\subsection{Token-Space Instability}
\label{subsec:rq2_token_flip}

The image-space degradation is gradual, but exact token identities are not stable. Table~\ref{tab:rq2_token_flip} and Figure~\ref{fig:rq2_token_flip} show the fraction of token positions that differ from the clean tokenization. At $\sigma=0.1$, VQGAN changes $75.1\%$ of token positions on average, and LlamaGen changes $79.5\%$. At $\sigma=0.2$, the flip rates rise to $89.0\%$ and $91.0\%$. At $\sigma=0.5$, both tokenizers are close to complete replacement, with flip rates above $97\%$.

LlamaGen reconstructs better in image space, yet it does not produce more stable exact token sequences---its mean flip rate is slightly higher than VQGAN's at every tested noise level. The implication is direct: reconstruction quality and token identity stability measure different things. A tokenizer can preserve broad visual structure while replacing most of the discrete sequence, so token IDs should not be interpreted as fixed semantic labels.

\subsection{Global Codebook Distribution}
\label{subsec:rq2_codebook_distribution}

The flip-rate metric measures per-position stability: it counts how often each token-grid position changes its token relative to the clean image. The global codebook statistics ignore position and ask a different question: whether the aggregate distribution over token IDs changes as noise increases. Table~\ref{tab:rq2_codebook_distribution} summarizes active-code counts, perplexity, and top-$k$ concentration; Figures~\ref{fig:rq2_active_codes},~\ref{fig:rq2_perplexity}, and~\ref{fig:rq2_top100_mass} visualize the main trends.

The two tokenizers have very different baselines. LlamaGen uses the full codebook on clean ImageNet, with 16{,}384 active codes and a perplexity of 16{,}179. VQGAN uses only 972 active codes, with a perplexity of 910. This reproduces the codebook-usage contrast from Chapter~\ref{ch:rq1}. Under noise, LlamaGen's active-code count remains high but decreases slightly, reaching 16{,}203 at $\sigma=0.5$. VQGAN's active-code count stays essentially fixed around 972, as shown in Figure~\ref{fig:rq2_active_codes}.

Perplexity is more sensitive than active-code count. LlamaGen's perplexity decreases from 16{,}179 to 6{,}434 as $\sigma$ increases from 0 to 0.5. VQGAN's perplexity decreases from 910 to 560. Thus, both distributions become more concentrated even when the number of active codes changes little. The top-100 mass confirms this concentration: LlamaGen increases from 0.012 to 0.115, while VQGAN increases from 0.165 to 0.388.

\section{Discussion}
\label{sec:rq2_discussion}

\subsection{Reconstruction Robustness and Token Robustness Diverge}
\label{subsec:rq2_reconstruction_token_divergence}

The chapter establishes a clear separation between reconstruction robustness and token robustness. LlamaGen holds a higher PSNR at every tested noise level, yet its token flip rate is slightly above VQGAN's at each perturbation level. The two properties move independently.

One plausible interpretation is codebook geometry. LlamaGen uses nearly the entire nominal codebook on clean ImageNet, whereas VQGAN uses a sparse active subset of 972 codes. A denser empirical vocabulary may place more nearest-neighbor boundaries near typical encoder outputs, so a small feature displacement can more easily change the assigned code. This would explain why LlamaGen can reconstruct better while still showing slightly higher token turnover. The experiment does not directly measure Voronoi cell sizes or encoder-feature distances, so this should be read as an interpretation of the observed pattern rather than a proven causal mechanism.

For autoregressive modeling this matters concretely: a sequence model trained on clean token sequences observes code indices, not pixels. If small image-space changes produce large sequence-level changes, then the learned prior over token sequences may be more sensitive to input perturbations than reconstruction metrics suggest. The results also argue against treating code indices as stable semantic labels---in both tokenizers, widespread token replacement is compatible with a visually coherent decoded output.

\subsection{Noise Concentrates Codebook Usage}
\label{subsec:rq2_noise_concentrates_usage}

The codebook statistics add a second layer to the token flip result. Noise does not merely permute token identities while preserving the global distribution. It also makes usage more concentrated. This is visible in the perplexity decrease for both models and in the increasing top-100 mass. For LlamaGen, the broad clean distribution contracts substantially under noise, despite retaining almost all codes as active. For VQGAN, the active set is already small, and noise shifts more probability mass toward the most frequent codes.

Active-code count alone would suggest that both tokenizers are nearly unchanged under noise. Perplexity and top-$k$ mass tell a different story: even without gaining or losing active codes, both distributions become more concentrated. The binary alive/dead status of a code is a coarser indicator than how much probability mass it receives.

\subsection{Relation to Subsequent Analyses}
\label{subsec:rq2_later_chapters}

Global noise mixes several effects simultaneously: it changes encoder activations everywhere, may move latent vectors across codebook boundaries, and alters the token grid the decoder receives. The chapters that follow decompose these mechanisms by localizing the perturbation to a single image patch in Chapter~\ref{ch:rq3}, and then directly editing a bounded token region in Chapter~\ref{ch:rq4}. The present experiment provides the reference point: token identity is highly unstable under global perturbation even when image-space reconstruction degrades gradually.

The previous chapter introduced discrete image tokenizers as the interface between images and autoregressive sequence models. This chapter fixes the experimental objects used in the rest of the thesis: the two tokenizers being compared, the image datasets on which they are evaluated, and the metrics used to describe reconstruction quality, codebook use, and spatial behavior.

\section{Models Under Study}
\label{sec:models_under_study}

The experiments compare two vector-quantized image tokenizers. The comparison is useful because the models share the same external task--mapping $256\times256$ images to discrete token grids--but differ in architecture and codebook design. If both tokenizers show the same behavior, the result is more likely to reflect a property of discrete image tokenization itself. If their behavior differs, the difference can be related to design choices such as embedding dimension, normalization, or training objective.

The first model is the ImageNet VQGAN first-stage tokenizer from Taming Transformers~\cite{esser2021taming}. It is a convolutional encoder--quantizer--decoder model trained with reconstruction, perceptual, and adversarial losses. The setting used here has downsampling factor $f=16$, so a $256\times256$ image becomes a $16\times16$ token grid. The nominal codebook contains $K=16{,}384$ entries, each with embedding dimension $256$.

The second model is the LlamaGen tokenizer~\cite{sun2024llamagen,llamagengithub}. LlamaGen is designed for Llama-style autoregressive image generation and provides tokenizers such as \texttt{VQ-16} and \texttt{VQ-8}. The primary comparison in this thesis uses \texttt{VQ-16}, which also maps $256\times256$ images to a $16\times16$ grid with nominal codebook size $K=16{,}384$. Its codebook embeddings are lower-dimensional ($d=8$) and assignments use L2-normalized encoder outputs and codebook entries.

Table~\ref{tab:model_config_summary} summarizes the shared and differing configuration choices. The table is included to make later results interpretable: equal grid size and vocabulary size make the sequence-level comparison controlled, while the differences in embedding geometry and training recipe give the experiments something meaningful to test.

\section{Datasets}
\label{sec:datasets}

The datasets serve two roles. ImageNet validation is the reference set: it is used for reconstruction baselines, codebook usage, global perturbation robustness, and locality experiments. The remaining datasets are used in Chapter 8 to test how reconstruction and codebook statistics change when the input distribution moves away from ImageNet.

\subsection{ImageNet Validation}
\label{subsec:imagenet_validation}

ImageNet was introduced as a large-scale visual recognition dataset organized around the WordNet noun hierarchy~\cite{deng2009imagenet}. It was collected to provide broad object-category coverage at a scale that earlier recognition datasets did not offer. The ImageNet Large Scale Visual Recognition Challenge (ILSVRC) later standardized a 1,000-class classification benchmark, commonly called ImageNet-1K~\cite{russakovsky2015imagenet}.

The primary reference set in this thesis is the ImageNet-1K validation split. It contains 50,000 images, with 50 images for each of 1,000 object classes. The images vary in original resolution and aspect ratio, so they are converted to RGB, resized, center-cropped to $256\times256$, and normalized according to the tokenizer being evaluated. No test-time data augmentation is used. This deterministic preprocessing is important because the experiments compare tokenizer behavior, not augmentation robustness.

\subsection{Shifted Datasets}
\label{subsec:shifted_datasets}

The shifted datasets are not used to repeat every experiment in the thesis. Their purpose is narrower: Chapter 8 uses them to ask whether the codebook and reconstruction behavior observed on ImageNet validation remains stable when the visual distribution changes. The datasets form two groups.

\paragraph{ImageNet-aligned shifts.}
ImageNet-V2 was collected as a new test set for the same 1,000 ImageNet classes, with the goal of measuring robustness to natural resampling of the benchmark distribution~\cite{recht2019imagenet}. It keeps the label space and natural-image setting close to ImageNet while changing the sampled images. This makes it a near-domain shift: changes in tokenizer behavior should mostly reflect resampled natural-image statistics rather than a new visual domain.

ImageNet-Sketch also keeps the ImageNet label space, but replaces natural photographs with black-and-white sketches~\cite{wang2019learning}. It is therefore a stronger shift than ImageNet-V2. Texture, color, and photographic detail are largely absent, while object shape remains central. This makes it useful for testing whether a tokenizer's vocabulary is tied mainly to natural-image texture statistics or can also represent more abstract object depictions.

\paragraph{Non-ImageNet domain checks.}
Chapter 8 also uses datasets whose visual domains are not ImageNet-like. ObjectNet contains household objects photographed under controlled variations in viewpoint, rotation, and background, and was designed to expose object-recognition brittleness outside standard ImageNet biases~\cite{barbu2019objectnet}. BloodMNIST and OrganAMNIST are part of MedMNIST v2, a lightweight benchmark suite for biomedical image classification~\cite{yang2023medmnist}: BloodMNIST contains RGB microscopy images of blood cells, while OrganAMNIST contains abdominal CT slices. RVL-CDIP contains scanned document pages labeled by document type~\cite{harley2015rvlcdip}. These domains test whether a tokenizer trained for natural images changes its codebook behavior when the input is microscopy, medical imaging, or document layout rather than ordinary object photographs.

\section{Metrics}
\label{sec:metrics}

The experiments evaluate tokenizers from several angles. First, a tokenizer should reconstruct the input image faithfully. Second, it should induce a usable discrete vocabulary rather than collapsing onto a small subset of codes. Third, its response to perturbations should be interpretable: a small or local change in the input should not necessarily imply arbitrary changes throughout the token grid or decoded image. These requirements lead to three metric families: sample-level image metrics, distribution-level image metrics, and representation-level metrics.

Sample-level metrics compare paired images, usually an input image $x$ and a reconstruction $\hat{x}$. They answer whether one reconstruction preserves one source image. Distribution-level metrics compare sets of images in a feature space. They answer whether the aggregate distribution of reconstructions resembles the reference distribution. In this thesis, the images being compared are reconstructions or perturbed reconstructions, not free samples from a newly trained generator, so distribution metrics are interpreted as reconstruction-distribution metrics rather than as standalone generative quality scores. Representation-level metrics measure the token sequence itself: which codes are used, how concentrated the code distribution is, and how token assignments change under perturbation.

\subsection{Evaluation Criteria}
\label{subsec:evaluation_criteria}

The metrics are organized by the following criteria:
\begin{description}
    \item[Pixel fidelity.] Agreement between aligned pixel intensities in $x$ and $\hat{x}$. Pixel fidelity is useful for measuring exact reconstruction error, but it can penalize small spatial shifts or perceptually negligible changes.

    \item[Perceptual fidelity.] Agreement in visual structure or learned feature space. These metrics are intended to better reflect perceived similarity than raw pixel error.

    \item[Distribution match.] Agreement between the feature distribution of reference images and the feature distribution of reconstructions or perturbed reconstructions.

    \item[Diversity and coverage.] Whether a set of outputs covers the reference feature manifold rather than matching only a narrow region.

    \item[Codebook efficiency.] How much of the nominal visual vocabulary is used and how concentrated token usage is. Perplexity is used here as an effective vocabulary-size measure: if the empirical token distribution were uniform over $M$ codes, its perplexity would be $M$.

    \item[Stability and locality.] Stability means that a controlled perturbation produces a controlled change in the tokenizer output. Locality asks where that change occurs: inside the perturbed image region, outside it, or across the whole grid.
\end{description}

\subsection{Sample-Level Reconstruction Metrics}
\label{subsec:sample_reconstruction_metrics}

Mean squared error (MSE) and peak signal-to-noise ratio (PSNR) are full-reference pixel metrics. For an image with $N$ scalar pixel values,
\begin{align}
    \mathrm{MSE}(x,\hat{x}) &= \frac{1}{N}\sum_{i=1}^{N}(x_i-\hat{x}_i)^2, \\
    \mathrm{PSNR}(x,\hat{x}) &= 10\log_{10}\!\left(\frac{\mathrm{MAX}^2}{\mathrm{MSE}(x,\hat{x})}\right).
\end{align}
For normalized images in $[0,1]$, $\mathrm{MAX}=1$. Lower MSE and higher PSNR indicate better pixel agreement. PSNR is widely used in image restoration but is known to be limited as a perceptual quality measure~\cite{huynh2008scope}.

SSIM compares local luminance, contrast, and structure rather than only pointwise pixel error~\cite{wang2004ssim}. In simplified form,
\begin{equation}
    \mathrm{SSIM}(x,y) = l(x,y)c(x,y)s(x,y),
\end{equation}
where $l$, $c$, and $s$ denote luminance, contrast, and structure comparisons computed over local windows. SSIM values are then averaged across the image. Higher SSIM indicates stronger structural similarity.

LPIPS compares deep network activations between two images~\cite{zhang2018unreasonable}:
\begin{equation}
    \mathrm{LPIPS}(x,y) = \sum_l w_l \left\lVert \phi_l(x)-\phi_l(y)\right\rVert_2^2,
\end{equation}
where $\phi_l$ denotes normalized features at layer $l$ and $w_l$ are learned weights. Lower LPIPS indicates greater perceptual similarity. Unlike MSE and PSNR, LPIPS is explicitly calibrated against human perceptual judgments, but its value depends on the chosen backbone and calibration.

\subsection{Distribution-Level Image Metrics}
\label{subsec:distribution_metrics}

FID compares two image sets by embedding them with an Inception network and fitting a Gaussian to each feature distribution~\cite{heusel2017gans}. For reference features with mean and covariance $(\mu_r,\Sigma_r)$ and reconstruction features with $(\mu_g,\Sigma_g)$,
\begin{equation}
    \mathrm{FID}
    =
    \lVert \mu_r-\mu_g\rVert_2^2
    +
    \mathrm{Tr}\!\left(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2}\right).
\end{equation}
Lower FID indicates closer feature distributions. In tokenizer papers, VQGAN and LlamaGen report reconstruction FID or rFID to measure whether reconstructions match the distribution of original images~\cite{esser2021taming,sun2024llamagen}. That use is appropriate here, but the interpretation is narrower than for unconditional generation: the model is reconstructing or perturbing existing images rather than sampling independent images from scratch.

sFID is a spatial variant used in common diffusion-model evaluator pipelines~\cite{dhariwal2021diffusion,openaiguideddiffusion,openaiguideddiffusionevals}. It uses spatial features rather than only pooled Inception features, so it can be more sensitive to spatial layout differences. It carries the same finite-sample and feature-extractor caveats as FID.

Inception Score combines classifier confidence and predicted-class diversity~\cite{salimans2016improved}:
\begin{equation}
    \mathrm{IS}
    =
    \exp\!\left(
        \mathbb{E}_{x\sim p_g}
        \left[
            \mathrm{KL}\!\left(p(y\mid x)\,\|\,p(y)\right)
        \right]
    \right).
\end{equation}
Higher IS means that individual images are confidently classified while the set spans multiple classes. It does not compare directly to real images, and later analyses emphasize that it can be misleading when used alone~\cite{barratt2018note,chong2019unbiased}.

Precision and recall for generative models separate fidelity from coverage in feature space~\cite{kynkaanniemi2019improved}. Precision measures how much of the output set lies near the real-data manifold; recall measures how much of the real-data manifold is covered by the output set. Figure~\ref{fig:precision_recall_tradeoff} illustrates this distinction.

\subsection{Codebook Usage Metrics}
\label{subsec:codebook_usage_metrics}

Let $n_k$ be the number of assignments to code $k$ over an evaluation set, let $N_t=\sum_{k=1}^{K}n_k$ be the total number of token assignments, and let
\begin{equation}
    p_k = \frac{n_k}{N_t}.
\end{equation}
The raw active-code count is
\begin{equation}
    A_{\mathrm{raw}} = \sum_{k=1}^{K}\mathbb{1}[n_k>0],
\end{equation}
and the active fraction is
\begin{equation}
    a_{\mathrm{raw}} = \frac{A_{\mathrm{raw}}}{K}.
\end{equation}
Raw activity is easy to interpret, but it is sensitive to one-off rare codes. When needed, an effective active set can be defined by a minimum support threshold or by the smallest set of codes covering a fixed cumulative mass.

Entropy and perplexity summarize how spread out the token distribution is:
\begin{align}
    H(p) &= -\sum_{k=1}^{K} p_k\log p_k, \\
    P(p) &= \exp(H(p)).
\end{align}
The intuitive meaning of perplexity is effective vocabulary size. If the tokenizer used exactly $M$ codes uniformly, then $P(p)=M$. A tokenizer may therefore have $K=16{,}384$ nominal entries but a much smaller effective vocabulary if the distribution is concentrated.

Top-$m$ mass measures concentration directly:
\begin{equation}
    M_m = \sum_{k\in \mathrm{Top}_m(p)} p_k,
\end{equation}
where $\mathrm{Top}_m(p)$ is the set of the $m$ most frequent codes. High top-$m$ mass means that a small set of codes accounts for a large fraction of assignments.

Finally, positional entropy computes the same entropy quantity at each grid position $(u,v)$ across the dataset. It asks whether different spatial positions use similar parts of the codebook or whether some positions specialize to particular tokens.

\subsection{Locality and Robustness Metrics}
\label{subsec:locality_robustness_metrics}

Robustness experiments compare the tokenizer output before and after a controlled perturbation. For global noise experiments in Chapter~\ref{ch:rq2}, the perturbation is applied to the whole image, and robustness is reported as the change in reconstruction metrics and codebook statistics as noise strength increases.

Locality experiments use spatial masks. For encoder locality in Chapter~\ref{ch:rq3}, a patch is perturbed in image space and the clean and perturbed token grids are compared. For token position $i$, define a flip indicator
\begin{equation}
    F_i = \mathbb{1}[t_i \ne t'_i],
\end{equation}
where $t_i$ and $t'_i$ are the clean and perturbed token IDs. For a set of token positions $R$,
\begin{equation}
    \rho(R) = \mathbb{E}_{i\in R}[F_i].
\end{equation}
The leakage ratio compares outside-patch and inside-patch flip rates:
\begin{equation}
    \lambda_{\mathrm{enc}} =
    \frac{\rho(R_{\mathrm{out}})}
         {\rho(R_{\mathrm{in}})+\epsilon}.
\end{equation}
The small constant $\epsilon$ avoids division by zero when no inside-patch flips occur. A low leakage ratio means that token changes are mostly confined to the perturbed region; a high value means that the encoder or quantizer has propagated the perturbation to distant token positions.

For decoder locality in Chapter~\ref{ch:rq4}, the intervention is applied directly to a bounded token patch and the decoded images are compared inside and outside the corresponding image-space region. The same idea is used: inside-region change measures whether the edit had an effect, while outside-region change measures leakage beyond the intended region.

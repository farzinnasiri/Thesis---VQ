\addcontentsline{toc}{chapter}{Introduction}
\label{ch:introduction}

This document is intended to be both an example of the Polimi \LaTeX{} template for Master Theses, as well as a short introduction to its use. It is not intended to be a general introduction to \LaTeX{} itself, and the reader is assumed to be familiar with the basics of creating and compiling \LaTeX{} documents.

The cover page of the thesis must contain all the relevant information: title of the thesis, name of the Study Programme and School, name of the author, student ID number, name of the supervisor, name(s) of the co-supervisor(s), if any, and academic year.

Since a thesis might be a substantial document, it is convenient to break it into chapters. Each chapter can be written in a separate file and then included in the main file with the command:

\begin{verbatim}
\input{Chapters/chapter_01}
\end{verbatim}

This thesis is organized as follows. Chapter~\ref{ch:chapter_one} introduces the main concepts and structure of the work. Chapter~\ref{ch:conclusions} presents the conclusions and possible future developments.

\chapter{Local Perturbations in Image Space}
\label{ch:rq3}

Global noise, as shown in Chapter~\ref{ch:rq2}, makes token identities highly unstable across the whole image. That experiment cannot separate the effect of perturbing the input everywhere from the tokenizer's response to a local change. This chapter isolates the question: when a bounded image region is corrupted, how far do the token changes spread?

The experiment adds Gaussian noise to an image patch corresponding to a square region of the $16\times16$ token grid, then compares the resulting token grid with the clean tokenization. Token changes are measured inside the corresponding token patch, outside it, and as a function of distance from the patch boundary. Both tokenizers react most strongly within the patch, but the response does not stop there: even at the lowest noise level tested, roughly 30\% of outside token positions carry a different token than in the clean encoding.

\section{Motivation}
\label{sec:rq3_motivation}

A convolutional tokenizer is spatial in an architectural sense: nearby pixels tend to contribute to nearby latent positions, and the output is arranged as a two-dimensional grid. That does not guarantee locality under perturbation. A latent cell can depend on pixels outside its nominal $16\times16$ image block, neighboring receptive fields can overlap, and nearest-neighbor quantization can turn a small feature shift into a discrete token change.

For autoregressive generation, the relevant input is the token sequence rather than the image. A local image-space change that causes widespread token changes is therefore more disruptive to the sequence representation than image-space metrics alone would suggest.

The global-noise experiment in Chapter~\ref{ch:rq2} cannot separate these cases, because every part of the input was perturbed. The patch experiment does: only part of the image is changed, so outside-patch token changes directly measure leakage through the tokenizer.

\section{Experimental Setup}
\label{sec:rq3_setup}

\subsection{Patch-Noise Protocol}
\label{subsec:rq3_patch_noise_protocol}

Let $x \in [0,1]^{H \times W \times 3}$ be a preprocessed ImageNet validation image and let $P$ denote a square patch in image space. The binary mask $M_P \in \{0,1\}^{H \times W \times 1}$ equals one inside the patch and zero outside it. For a noise level $\sigma$, the perturbed image is
\begin{equation}
    x_{\sigma,P}
    =
    \mathrm{clip}\!\left(x + \sigma \epsilon \odot M_P, 0, 1\right),
    \qquad
    \epsilon \sim \mathcal{N}(0,I).
    \label{eq:rq3_patch_noise}
\end{equation}
Only pixels inside $P$ receive additive noise. The clipping operation keeps the image in the valid pixel range.

Both tokenizers produce a $16 \times 16$ token grid. The main Gaussian-noise analysis uses an $8 \times 8$ token-space patch, corresponding to one quarter of the token grid and approximately one quarter of the image area under the tokenizer downsampling. The patch location is recorded for each image in both pixel and token coordinates, so inside/outside regions are measured from the actual perturbation mask. The reported noise levels are $\sigma \in \{0.1, 0.25, 0.5\}$. A masked-occlusion variant is reported separately as a stronger local intervention.

\subsection{Inside and Outside Response}
\label{subsec:rq3_inside_outside_metrics}

Let $z_0 \in \{1,\ldots,K\}^{16 \times 16}$ be the clean token grid and $z_{\sigma,P}$ be the token grid obtained from the patch-perturbed image. Let $I_P$ be the set of token positions covered by the patch and let $O_P$ be the complement. The inside response is the mean token flip rate inside the perturbed patch:
\begin{equation}
    R_{\mathrm{in}}(\sigma,P)
    =
    \frac{1}{|I_P|}
    \sum_{i \in I_P}
    \mathbf{1}\!\left[z_{\sigma,P,i} \neq z_{0,i}\right].
    \label{eq:rq3_inside_response}
\end{equation}
The outside response is the same quantity measured outside the perturbed region:
\begin{equation}
    R_{\mathrm{out}}(\sigma,P)
    =
    \frac{1}{|O_P|}
    \sum_{i \in O_P}
    \mathbf{1}\!\left[z_{\sigma,P,i} \neq z_{0,i}\right].
    \label{eq:rq3_outside_response}
\end{equation}
The ratio
\begin{equation}
    \lambda(\sigma,P)
    =
    \frac{R_{\mathrm{out}}(\sigma,P)}
         {R_{\mathrm{in}}(\sigma,P) + \varepsilon}
    \label{eq:rq3_leakage_ratio}
\end{equation}
is used as a compact leakage measure. A value near zero means that token changes are mostly confined to the patch. A value near one means that outside tokens change almost as often as inside tokens. In this chapter, all response values are token-flip probabilities: they are fractions of token positions whose discrete ID differs from the clean encoding.
Thus, $R_{\mathrm{in}}$ measures direct sensitivity to the corrupted patch, while $R_{\mathrm{out}}$ measures leakage outside the patch. The ratio $\lambda$ is useful only together with the two absolute rates, because a ratio can be large either because the outside response is large or because the inside response is small.

\subsection{Distance Profile and Concentration}
\label{subsec:rq3_distance_metrics}

The inside/outside split is useful but coarse. It says how much response leaves the patch, but not how far it goes. Each token position $i$ is therefore assigned a Manhattan grid distance $d(i,P)$ to the nearest token in $I_P$: distance zero is inside the patch, distance one is the first ring of neighboring token cells, and larger values move farther across the token grid. The distance profile is
\begin{equation}
    R_d(\sigma,P)
    =
    \frac{1}{|\{i : d(i,P)=d\}|}
    \sum_{i : d(i,P)=d}
    \mathbf{1}\!\left[z_{\sigma,P,i} \neq z_{0,i}\right].
    \label{eq:rq3_distance_profile}
\end{equation}
The results report the full profile and a small set of bands: inside tokens ($d=0$), boundary-neighbor tokens ($d=1$), near tokens ($d \in \{1,2\}$), and far-field tokens ($d \geq 6$).

The outside response can also be diffuse or concentrated. For each outside token position, the analysis estimates its flip frequency across the validation set. Let $a_i$ denote this empirical response value for position $i \in O_P$, and let $T_{0.05}(O_P)$ be the 5\% of outside positions with the largest response values. The outside concentration score is
\begin{equation}
    C_{0.05}(\sigma,P)
    =
    \frac{\sum_{i \in T_{0.05}(O_P)} a_i}
         {\sum_{i \in O_P} a_i + \varepsilon}.
    \label{eq:rq3_outside_concentration}
\end{equation}
This top-5\% outside mass is used only as a diagnostic. It tells whether outside-patch changes are spread over many positions or dominated by a small subset of high-response positions.

\label{subsec:rq3_inside_outside_results}

Table~\ref{tab:rq3_inside_outside_summary} reports the mean inside response, outside response, leakage ratio, and far-field response. The inside response is high for both tokenizers because the perturbation directly modifies the patch. At $\sigma=0.1$, VQGAN changes 78.8\% of inside tokens and LlamaGen changes 82.2\%. At $\sigma=0.5$, the inside response is almost saturated for both models.

Outside the patch, the response is already approximately 30\% at the lowest noise level. At $\sigma=0.25$, it rises to 44.1\% for VQGAN and 42.8\% for LlamaGen. At $\sigma=0.5$, it reaches 52.1\% for VQGAN and 50.5\% for LlamaGen. The leakage ratio also increases with $\sigma$: at the high level, outside tokens change about half as often as inside tokens.

\subsection{Outside-Response Concentration}
\label{subsec:rq3_concentration_results}

The outside response also changes in spatial distribution. If a few outside positions explained most of the response, the leakage would be sparse. Instead, the top-5\% outside mass decreases as the perturbation becomes stronger, as shown in Table~\ref{tab:rq3_outside_concentration_summary}. For VQGAN, the top-5\% outside mass is 0.198 at $\sigma=0.1$, 0.123 at $\sigma=0.25$, and 0.102 at $\sigma=0.5$. LlamaGen follows the same pattern, with values 0.198, 0.127, and 0.106. Lower top-5\% mass means that the outside response is spread across more outside positions rather than concentrated in a few hotspots.

\subsection{Masked Patch Intervention}
\label{subsec:rq3_masked_results}

The masked-patch variant tests whether the same pattern appears under a stronger local intervention. Table~\ref{tab:rq3_masked_summary} shows that masking nearly saturates the inside response for both tokenizers, while the outside response remains large: 56.3\% for VQGAN and 49.5\% for LlamaGen. The masked result sharpens the patch-noise finding: even when the intervention is confined to one quarter of the image, the tokenizer can carry disruption to roughly half of the remaining token grid.

\section{Discussion}
\label{sec:rq3_discussion}

Both tokenizers preserve a spatial gradient of response, but not strict spatial locality. The response is strongest inside the perturbed patch and near its boundary, yet far-field tokens change at every noise level. VQGAN and LlamaGen are also closer to each other here than in the clean reconstruction and codebook-usage results. LlamaGen has a slightly higher inside response at low noise and a slightly lower leakage ratio at each reported level, but the overall pattern is shared.

Several mechanisms in the encoder-tokenizer pipeline can plausibly contribute to this non-local leakage:
\begin{enumerate}
    \item \textbf{Receptive field overlap}: Standard convolutional encoders downsample the image through stacked layers with overlapping windows. A latent grid cell can therefore depend on pixels outside the nominal image block associated with that cell.
    \item \textbf{Spatial normalization}: If normalization statistics are computed over spatial feature maps, a localized perturbation can change feature statistics beyond the visibly corrupted region.
    \item \textbf{Quantization boundary amplification}: Nearest-neighbor quantization is discontinuous. A small continuous feature shift can cause a discrete token flip when the feature lies near a codebook boundary.
\end{enumerate}
Together, these mechanisms provide a plausible explanation for why the local visual changes measured here alter the discrete sequence representation outside the corrupted patch.

This result complements Chapter~\ref{ch:rq2}. Global noise showed that token identity is unstable when the whole image is perturbed. The patch experiment shows that the instability is not merely a consequence of perturbing every pixel. A bounded image-space perturbation can still alter many tokens outside the patch. For downstream autoregressive generation, locality in pixel space does not translate directly into locality in the discrete sequence.
